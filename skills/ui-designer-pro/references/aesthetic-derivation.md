# Aesthetic Derivation

Use this reference when creating a new visual direction or when a design feels
generic.

## 1. Derive, Do Not Preset

Start from:
- product world
- audience
- brand attributes
- physical / cultural references
- workflow character
- trust requirements

Extract visual properties rather than copying a style.

Example:
A clinical operations product may derive:
- calm blue atmospheric field
- crisp white functional surfaces
- restrained semantic color
- precise typography
- clear risk accents

The result can feel branded without becoming decorative.

## 2. Typography Voices

Possible families:
- neo-grotesque: neutral confidence
- geometric sans: engineered clarity
- humanist sans: approachable clarity
- condensed sans: density / urgency
- serif: editorial / institutional character
- mono: technical / data precision

Use actual product fit, language coverage, rendering quality, and licensing.

Do not ban a common typeface simply because it is common.
Reject defaults only when they fail the intended voice.

## 3. Layout Structures

Possible structures:
- dense workspace
- split-stage
- editorial column
- full-bleed
- dashboard grid
- ledger/index
- asymmetric composition
- modular cards
- single-focus ceremony

Choose from task and content behavior.

## 4. Color Logic

Options:
- tonal field
- brand accent + neutrals
- material palette
- restrained functional color
- complementary tension
- atmospheric gradient
- data-forward functional palette

Keep semantic and decorative systems separate.

## 5. Product-World Transfer

Borrow properties, not costumes.

Examples:
- healthcare → chart clarity, calm surfaces, precise labels
- finance → tabular discipline, ledger structure
- developer tools → mono/data rhythm, grid precision
- travel → wayfinding, ticket structures
- creative tools → canvas-first composition

## 6. Signature Elements

A signature element is optional.

It can be:
- recurring geometry
- distinctive typography
- surface strategy
- unique rule/divider language
- branded data motif
- image treatment
- atmospheric gradient system

Use one only when it helps recognition or emotional value.

## 7. Anti-Convergence

If the design feels generic:
- change the hierarchy carrier
- derive color from the product world
- make density intentional
- use a stronger typographic voice
- change the surface strategy
- design the most product-specific screen first

Do not solve genericness by adding random effects.
