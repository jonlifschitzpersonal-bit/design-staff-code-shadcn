# Art Direction and Graphic Design Foundations

Use this reference when a screen feels generic, flat, visually unresolved, or
when deciding between flat, tonal, gradient, layered, editorial, technical,
clinical, premium, playful, or other visual directions.

## 1. Art Direction Is a System

Art direction is the coherent relationship between:
- typography
- color
- surfaces
- light
- depth
- shape
- spacing
- imagery
- iconography
- motion
- density

Do not add effects independently.

A polished interface usually has one dominant material idea and a small set of
supporting rules.

## 2. Derive the Material Strategy

Ask:
- What should this product feel like?
- How much trust or seriousness is required?
- How long do users spend in it?
- How dense is the work?
- Is the screen operational, analytical, transactional, expressive, or
  emotional?
- Is brand atmosphere helpful or distracting?

Then choose a strategy.

### Flat / utilitarian
Best when:
- speed and density dominate
- platform familiarity is valuable
- repeated professional use matters

### Tonal
Uses related surface tones and restrained boundaries.
Best when:
- calmness and hierarchy matter
- the product needs sophistication without obvious effects

### Layered
Uses surface contrast, selective borders, and restrained elevation.
Best when:
- nested structure and workspace depth matter

### Atmospheric / gradient
Uses subtle color transitions in the canvas or large fields.
Best when:
- brand character or environmental softness matters
- white functional surfaces need separation from the canvas
- depth can replace excessive shadow

### Editorial
Uses typography, whitespace, and composition as primary carriers.
Best when:
- content hierarchy and brand voice dominate

### Technical / data-forward
Uses dense grids, mono/tabular numerals, precise rules, and restrained
semantic color.
Best when:
- speed of comparison and expert use dominate

These can be combined, but one should lead.

## 3. Gradient Decision Framework

A gradient is justified when it does at least one useful job:

### Spatial
Separates canvas from surfaces or suggests depth.

### Brand
Creates a recognizable atmosphere or color relationship.

### Attention
Guides the eye toward a focal region.

### Material
Suggests light, translucency, or a controlled surface transition.

### Emotional
Adds warmth, calm, energy, softness, or premium character appropriate to the
product.

If none applies, use a flat or tonal surface.

### Good gradient discipline
- keep transitions intentional
- ensure text contrast across the entire field
- avoid strong hue changes behind dense data
- prefer restrained ambient gradients for operational products
- test at different displays for banding and contrast
- do not use gradient as semantic status color
- do not make every surface gradient-bearing

### Clinical / health context
A soft atmospheric gradient can create calm and surface separation without
making the interface playful.
Keep critical clinical semantics independent from decorative background color.

## 4. Composition

Strong composition creates an order before details are read.

Control:
- dominant / supporting / quiet regions
- visual center of gravity
- vertical rhythm
- left/right balance
- edge tension
- whitespace fields
- repeated alignments
- deliberate breaks in the grid

Use asymmetry when it helps hierarchy.
Use symmetry when stability and clarity are more useful.

## 5. Figure / Ground

Users should immediately understand:
- what is canvas
- what is functional surface
- what is overlay
- what is selected
- what is interactive
- what belongs together

You can create figure/ground using:
- tonal contrast
- boundaries
- whitespace
- shadow
- blur
- layering
- scale
- grouping

Do not put every group in a card when whitespace can explain the structure.

## 6. Visual Weight

Visual weight increases with:
- saturation
- darkness / contrast
- size
- boldness
- containment
- iconography
- edge sharpness
- isolation
- unusual shape

Use it as a limited resource.

A small saturated red badge may outweigh a large neutral title.
Judge hierarchy perceptually, not only by component dimensions.

## 7. Rhythm

Rhythm comes from repeated relationships:
- label → value
- row → row
- section → section
- card padding
- baseline
- column alignment

Avoid spacing drift:
16, 17, 19, 21 px used accidentally is not nuance.

Allow optical correction when deliberate.

## 8. Typography as Architecture

Define:
- display / page title
- section title
- body
- label
- metadata
- numerical data
- status text

For analytical products:
- use tabular numerals where alignment helps
- align decimal precision
- keep units visually subordinate but clear
- do not make every label uppercase
- consider condensed type only where density and legibility support it

## 9. Shape Language

Radii, icon corners, input shapes, and containers form a visual family.

Do not mix:
- highly pill-shaped controls
- sharp cards
- bubble-like badges
- unrelated icon corner styles

unless hierarchy or brand intentionally requires contrast.

Pills should be semantically justified, not a default shape for all metadata.

## 10. Optical Refinement

Check:
- icon appears centered, not merely mathematically centered
- text baseline aligns with neighboring controls
- circle icons may need optical offsets
- nested radii feel related
- vertical padding looks balanced at actual font metrics
- mixed-case and all-caps labels occupy different visual weight
- badges with icons may need asymmetric padding

## 11. Product Appropriateness

Do not optimize for screenshot novelty.

A senior visual direction balances:
- brand expression
- usability
- accessibility
- task speed
- trust
- fatigue
- implementation cost

The best art direction is the one that makes the product feel inevitable for
its context.
